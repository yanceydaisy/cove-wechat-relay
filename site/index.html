WeChatResonance

一条微信消息，两种 AI 运行路径。

同一套本地收发、鉴权、排队与回执协议，可以接入 ChatGPT Work，也可以进入 Codex 侧的自用运行环境。这不是另一份聊天客户端，而是一条可被检查、重试和迁移的消息链。

官端路线

可复现、可部署、已经开源

  1. 01Windows Adapter 读取指定私聊的文字消息
  2. 02VPS Bridge 合并短消息并触发 MCP Events
  3. 03ChatGPT Work 读取事件并生成回复
  4. 04回复经长轮询、发送确认与 ACK 回到微信

协议，而非提示词魔法

每一轮消息都有可观察的生命周期。

Capture

捕获

只监听白名单会话；为消息生成稳定事件 ID。

Queue

排队

短消息合并成一轮；重复事件不会再次创建。

Wake

唤醒

官端订阅 MCP Events；自用路线替换模型入口。

Acknowledge

确认

真实发送后回 ACK；命令 ID 防止同一气泡发送两次。
