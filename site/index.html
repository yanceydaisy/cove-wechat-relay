I

Official route / public edition

官端路线

可复现、可部署、已经开源。它保持最小，只证明文字聊天接力这条基线。

  1. Capture读取指定私聊，生成稳定事件 ID。
  2. QueueBridge 合并短消息，重复事件不会再建一轮。
  3. WakeMCP Events 将一轮消息送入 ChatGPT Work。
  4. Acknowledge真实发送完成后回 ACK，避免重复气泡。

II

Codex route / private edition

Codex 路线

日常自用的工作系统。分享架构与迁移方法，个人登录态、消息和源码仍留在封面之内。

  1. Durable inbox入站消息先持久化，断网恢复后继续投递。
  2. Workspace进入 Codex 会话与工具环境，而非另造聊天前端。
  3. Media图片、表情与桌面能力按验证状态逐项扩展。
  4. Private datatoken、wxid、真实消息和私有配置不进入公开仓库。
